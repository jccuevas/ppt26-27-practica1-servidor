## Descripción 
En esta práctica se introducirá en el uso de las primitivas Socket para la programación de clientes y servidores sobre el protocolo TCP en una red IP, empleando el lenguaje 
C. Para ello se mostrará el funcionamiento de un cliente y un servidor sencillos sobre TCP cuyos códigos estarán disponibles en el espacio de esta asignatura en la 
plataforma de docencia virtual de la Universidad de Jaén. El cliente y el servidor son totalmente funcionales, aunque no están completos y pueden dar errores de 
ejecución, cuya solución es parte de la presenta práctica. 
Para profundizar en el conocimiento sobre las primitivas Sockets y este tipo de aplicaciones de comunicaciones, al código entregado se le deberán hacer diversas 
modificaciones para añadirle un nuevo servicio basado en un sencillo protocolo de aplicación. 
La práctica se estructurará en una serie de tareas distribuidas entre las diferentes sesiones de laboratorio establecidas para la práctica.
